# Frontend — AI-Powered Software Testing Assistant

Modern React 18 frontend built with Vite, React Router v6, Axios, and Vanilla CSS design tokens.

## Features
- JWT Authentication (Login, Register, Session persistence)
- Quality Dashboard (Metrics, Pass Rate gauge, Activity logs)
- Project & Requirement Management
- AI Requirement Analysis Workbench
- AI Test Scenario & Test Case Generator
- Interactive Test Execution tool with auto-bug filing
- Bug Reports & AI Bug Diagnostics Report Viewer

## Run Locally
```bash
npm install
npm run dev
```

The app will start at `http://localhost:5173` with proxy set up for the FastAPI backend at `http://localhost:8000`.
